Common Errors by Language

Python Common Bugs

ErrorTypical CauseQuick Fix
AttributeError: 'NoneType' Called method on None — forgot to check return value Add if result is not None: guard
TypeError: unhashable type: 'list' Used a list as a dict key or set element Convert to tuple()
KeyError: 'x' Accessing dict key that doesn't exist Use dict.get('x', default)
RecursionError Missing base case in recursive function Add base case; check termination condition
Mutable default argument bug def f(lst=[]): — shared across calls Use def f(lst=None): lst = lst or []

JavaScript TypeScript Common Bugs

ErrorTypical CauseQuick Fix
Cannot read properties of undefined Accessing property on undefined/null object Use optional chaining obj?.prop
Unhandled promise rejection Missing await or no .catch() Add await + wrap in try/catch
this is undefined Arrow function vs regular function context Use arrow function or .bind(this)
Stale closure in loop var in loop captured by closure Replace var with let
TS Type 'X' is not assignable to type 'Y' Wrong type passed; missing type narrowing Add type guard or cast appropriately

Universal Off-by-One & Boundary Bugs

# Wrong — misses last element
for i in range(len(arr) - 1):
    process(arr[i])

# Correct
for i in range(len(arr)):
    process(arr[i])

# Or better
for item in arr:
    process(item)

Test Writing Quick Reference

Python pytest Template

import pytest
from mymodule import my_function

# Regression test — covers the exact bug
def test_my_function_handles_none_input():
    result = my_function(None)
    assert result == []  # or whatever the correct behavior is

# Happy path
def test_my_function_normal_case():
    result = my_function([1, 2, 3])
    assert result == [2, 4, 6]

# Edge case
def test_my_function_empty_list():
    result = my_function([])
    assert result == []

# Expected exception
def test_my_function_invalid_type():
    with pytest.raises(TypeError):
        my_function("not a list")

JS TS Jest / Vitest Template

import { myFunction } from './myModule';

describe('myFunction', () => {
  // Regression test
  it('handles null input without throwing', () => {
    expect(() => myFunction(null)).not.toThrow();
    expect(myFunction(null)).toEqual([]);
  });

  // Happy path
  it('returns doubled values for normal input', () => {
    expect(myFunction([1, 2, 3])).toEqual([2, 4, 6]);
  });

  // Edge case
  it('returns empty array for empty input', () => {
    expect(myFunction([])).toEqual([]);
  });

  // Async
  it('resolves with data on success', async () => {
    const result = await myAsyncFunction('valid-id');
    expect(result).toHaveProperty('id');
  });
});

Debug Checklist

  1. 📍 Read the full error — error type, file, line number
  2. 🔎 Trace the stack — follow the call chain to root cause
  3. ❓ Ask: why did this happen? — not just what failed
  4. 🔁 Check: null/undefined/None — most common culprit
  5. ⚡ Check: async/await — missing await is a silent killer
  6. 🔢 Check: off-by-one — especially in loops and array indexing
  7. 📦 Check: imports/exports — wrong module, wrong named export
  8. ✅ Write the regression test first, then the fix
